# EXSPACE / Acustik Space

Образовательная платформа о космических исследованиях для NASA Space Apps. Истории миссий, комиксы, видео и игры с Акустиком — нашим вымышленным ИИ-помощником.

## Возможности

- 58 коллекций миссий с комиксами, историями и встроенной читалкой.
- Раздел Videos со встроенными YouTube-видео и поиском.
- Игры Akustik: The Way Home и Space Flight.
- Интерактивный раздел Solar System.
- Анимированный 2D-Акустик с подключением Gemini или OpenAI через сервер.
- Регистрация, избранное и сохранение результатов викторин.

## Локальный запуск

Нужен Python 3.10 или новее. Node.js используется для проверок и альтернативной команды запуска. Установка npm-пакетов для запуска не требуется.

```sh
python -m backend.server
```

Откройте http://localhost:5173. Также можно использовать `npm start`.

## Подключение Акустика

Скопируйте `.env.example` в `.env` в корне проекта и укажите собственный ключ:

```dotenv
AI_PROVIDER=gemini
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-3.8-flash
```

Для OpenAI укажите `AI_PROVIDER=openai`, `OPENAI_API_KEY` и `OPENAI_MODEL`. Доступность моделей зависит от аккаунта провайдера.

Характер, биография и правила ответов находятся в `backend/akustik_instructions.txt`. Настройки читаются при каждом запросе. Без ключа сайт работает, но ИИ-ответы недоступны.

API-ключ хранится только на сервере. Не добавляйте `.env` в Git. База пользователей `data/acustik.sqlite3`, служебные настройки хостинга, временные файлы и локальные кэши исключены через `.gitignore`. В `.env.example` нет настоящих ключей.

## Проверки

```sh
python tools/check_public_files.py
npm run check
python -m unittest backend.test_auth backend.test_akustik
```

GitHub Actions запускает проверки при отправке изменений и создании pull request. Проверка публичных файлов ищет известные секреты из локального `.env`, распространённые форматы ключей и слишком большие файлы; она не заменяет ручной просмотр перед публикацией.

## Открытый репозиторий и работающий сайт

В репозитории находятся исходный код и материалы сайта, чтобы организаторы могли изучить и запустить проект. Полная копия с материалами занимает около 2 ГБ.

GitHub-репозиторий и работающий сайт — разные вещи. Статический хостинг может показывать папку `dist`, но ИИ-чат и аккаунты требуют Python-сервер и приватные переменные окружения. Текущий сервер предназначен для локального запуска; для публичного размещения нужны настройка допустимого домена, HTTPS и подходящий сервер.
